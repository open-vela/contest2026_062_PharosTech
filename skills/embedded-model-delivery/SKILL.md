# 嵌入式模型独立交付

先固定“哪个模型文件给哪个runtime/SoC使用”，再选传输方式。已知hash只标识内容，不证明来源可信或可再分发。

1. 清单分别记录模型/runtime/固件、原始来源与revision、转换参数、目标profile、文件bytes/hash和许可材料；未知项保持未知，不能用当前HEAD补造历史版本。
2. staging只装清单列出的文件，拒绝路径穿越/软链接/重复路径，核对实际字节和整文件hash。不要把开发目录、私人录音或聊天缓存整包带走。
3. 断点上传记录总长、offset和版本身份，完成后整体校验；收到HTTP成功或USB传输完成不等于持久化完成。
4. 跨OS模型只交给有权读取的服务，计算域无存储时按逻辑名称从控制域拉到tmpfs；generation变化关闭旧句柄。
5. 缓存命中必须核对有效身份，分别测首传含摘要、冷加载和复用；保留空间/内存不足时的明确失败。

[清单、路径及K7案例](references/runbook.md)、[工具出处](references/sources.md)。交付可验证的包与部署测量；打包不自动发布，也不把工具中的许可字段改成approved来绕过授权。
