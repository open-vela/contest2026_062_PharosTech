# 小模型的可靠设备动作

先用真实工具表评估模型能否正确调用，不因为输出JSON格式正确就相信意图和参数正确。

- 明确操作意图用规则识别，纯询问/否定/闲聊保留聊天路径；不确定时不擅自执行。规则提取可靠参数，只有缺槽时向模型提供单个候选工具。
- 对模型参数做类型、范围、枚举、相对量、时区与单位校验。相对音量需要当前设备状态，不能由模型随意给绝对0。
- 经原产品tool gateway/Broker执行，沿用实际主体的scope与审批；合成tool call不得提升外部MCP用户为主人权限。
- 区分已排队、等待审批、运行中、实际成功、失败与取消；请求幂等和副作用状态不能由聊天文案推导。
- 工具事实用确定性模板呈现；模型只负责不改变事实的自由聊天，不再让它改写时间/数量/失败状态。
