# 端侧多模型同驻与并发测量

先定义要回答的部署问题，例如三模型能否同时驻留、并发是否降低首响，固定输入和测量口径再跑。

1. 保存模型/runtime/固件hash、线程、CPU/NPU策略、context、输入长度与清KV/缓存规则。不要同时调频、换模型又改线程然后归因一个因素。
2. 分冷顺序加载、冷同时加载、热缓存重载、稳态单路计算和多路重叠；“单路”若其他模型仍驻留必须注明。
3. 采初始化和运行期的MemAvailable、PSS/RSS/VmHWM、进程CPU时间、温度/频率；采样间隔与开销也记录。
4. 每轮核对返回值和输出身份，warmup与重复次数明确；保留离群和失败，不只挑最低延迟。
5. 根据资源争用和首回调分布提出串行/重叠/常驻策略，区分观察与调度根因推断。
