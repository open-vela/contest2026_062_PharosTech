# Nyabula 实机界面图集

[返回项目主页](../README.md) · [产品详解](product/README.md)

以下为 B109 设备与本轮更新面板的实机截图。桌面矩阵以 1440×900 视口的深色界面采集，超过视口的页面按内容高度截成长图；浅色、手机和平板代表页另列。账号、身份与设备标识等敏感信息已遮盖，摄像头预览保持关闭。截图展示采集时的页面状态，功能验证范围见[验证记录](validation/README.md)。

共 210 张，覆盖三主题基础页面、已安装插件详情与权限、登录页及浅色/手机/平板代表页，其中 89 张为内容长图。首次设密、配网、瞬时连接和未登录云账号的设备详情未采集；物品学习、健康、电量与家居入口未发布，不列入图集。
