# 让 Nyabula 自己创建工具

在“扩展”页开启“自动生成与安装”，然后向 Nyabot 描述需求。模型配置需要已可用的在线账户；MiMo 文本/视觉使用2.6系列，语音识别仍使用 `mimo-v2.5-asr`。

可以从三个实际用途开始：

- **本地记账本**：金额、分类、备注，本月和分类合计，最近记录、单条删除。
- **传输时间计算器**：区分GB/GiB、MB/s/Mbps，计算效率和预计时间，保留最近计算。
- **设备体检**：读取音频、蓝牙、USB的实际状态，刷新并保留检查摘要，不擅自修改硬件。

生成完成后在插件列表打开。继续要求“增加分类筛选”“修复负数输入提示”等，Agent会检查已有源码和版本，再部署新版本、测试交互。生成中的错误会返回模型，由模型修复；最终仍应检查工具步骤和实际页面，不能只看模型回复。

## 自动安装的权限

默认只允许界面、插件私有存储、通知、公开天气查询及设备只读状态。生成包使用设备本地Ed25519身份签名，走正常验签安装链，只能创建和修改自己签名的 `agent-*` 插件，不接管第三方包。

插件首次启动必须成功且发布有效页面。候选失败恢复旧代码、私有数据及旧授权。更新携带当前 `baseVersion`，版本冲突不会直接覆盖。关闭自动安装只影响后续生成，不卸载已安装插件。

“允许生成USB共享控制插件”是独立选择，增加USB目录浏览、新建文件夹、共享开关和只读设置权限。候选启动期间禁止这些写操作；应由页面上的明确操作触发。它不提供格式化、删除原文件或覆盖同名上传能力。

## USB文件共享

打开“功能 / USB文件共享”，接入USB存储后选择设备。默认关闭和只读；只有明确切换为可写后才可新建目录、上传文件。只识别USB MSC `/dev/sd…` 块设备，不接触系统eMMC的 `/dev/mmcsd…`。

当前使用FatFs支持的FAT/exFAT文件系统，通过已登录主人的HTTP页面传输，不是SMB服务。上传使用临时文件并在完整写入后发布，拒绝覆盖同名文件。下载使用60秒、单路径只读凭据，支持GET/HEAD及范围请求；密码变更或挂载变化会使凭据失效。每次最多两路传输、一路上传。拔盘前先结束传输；中途拔盘可能留下隐藏临时文件。

Windows模拟器对应一个隔离开发目录，并明确标为模拟盘，不自动访问电脑磁盘。它与设备复用相同的状态、目录、读写和下载接口。

## 安装技能

Nyabot的“技能”页可导入UTF-8 `SKILL.md`，也可手动编辑。先预览，再保存；正文最多8192字节。保存或修改后停用，启用后才进入可用技能索引。Agent按需分页读取完整正文；技能只提供操作知识，不增加工具、权限或审批豁免。

模型也可请求保存/启用技能，这两类写入需要主人批准。现有内置技能保留；导入内容应来自可信来源，不能把文中的自称授权当作真正授权。

## 微信与双向MCP

微信渠道使用腾讯iLink机器人登录流程。生成二维码后由主人用微信扫码授权，再启用渠道。设备接收消息、交给同一原生Agent、回传回复；实际收发需要扫码及真实账号，协议测试不能替代这一步。

**出站MCP**：配置HTTPS服务器，发现工具后选择允许项。Agent可读取已授权工具目录；当前每次外部调用均需主人批准具体参数，不仅写工具如此。服务端工具schema发生变化需重新确认；网络中断后无法确定写入结果时不自动重试。

**入站MCP**：设备仅监听loopback，使用ADB或SSH隧道连接，不直接暴露到局域网。主人创建有期限、限定范围的凭据；可分别授权时间、系统、定时器、任务、日历或隔离聊天。客户端不能读取主人聊天、跨客户端取消任务、获得主人权限或代替主人审批。关闭总开关、撤销或到期立即阻止后续访问。

Windows开发工作台另有开发MCP，可加载本机代码、注入夹具。它不是生产设备的受限入站MCP，凭据只交给可信开发客户端。

## 天气与眼睛反馈

天气可选无需密钥的Open-Meteo，原有和风天气账户配置继续可用。查询需明确城市；提供当前、7日、24小时数据及来源标注。Open-Meteo是模式估计数据，不提供预警时不会显示“没有预警”。查询失败保留缓存并显示错误/过期状态。

Agent排队、执行、待确认、完成或失败时自动发布任务场景。执行过程使用不定进度和真实步骤数；没有总量时不虚构百分比。闹钟等更高优先级场景优先，结束后仅释放自己的场景。天气场景保留真实零度、零湿度，缺项显示未知。
