# 本地记账本

由KICKPI-K7设备上的Nyabula Agent调用MiMo 2.6 Flash生成并迭代至1.0.14。示例保留实际生成源码，ID改为sample-ledger-cn，避免覆盖设备的agent-ledger-cn；不含任何记账数据、身份文件或模型密钥。

功能：金额按分存储、本月及分类合计、最近10笔、分类筛选、按编号删除。单个存储值按4096 UTF-8字节检查容量，非法金额在页面提示。

Windows工作台加载此目录，逐项授予manifest声明的4项权限，然后启动。设备发布使用SDK build/test/pack及自己的签名密钥，不复制设备作者私钥。

原生实测：3.50/12.50正数、0/负数/abc拒绝、__proto__/constructor/a-b/a b分类及筛选、升级保留8.80、12笔80个汉字备注后容量保护均通过。数字为隔离验收数据，不随示例分发。

许可证：Apache-2.0。
