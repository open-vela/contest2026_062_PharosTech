# 文件传输时间计算器

由设备上的Nyabula Agent读取transfer-planning技能后调用MiMo 2.6 Flash生成，并根据实际按钮/清空缺陷反馈迭代到1.0.10。ID改为sample-transfer-planner，源码逻辑保持模型交付版本；无用户数据或密钥。

输入容量、速度和有效效率，明确选择GB/GiB、Mbps/MB/s。仅做数学估算，不执行测速或改变文件共享。最近5次成功计算保存在私有存储，清空按钮删除该插件自己的历史。

原生浏览器按真实按钮验证：8 GiB / 100 Mbps / 80%=858.993459秒；8 GB / 100 Mbps / 80%=800秒；8 GB / 100 MB/s / 80%=100秒。错误输入不写历史；清空显示暂无历史。

Windows工作台加载目录、授予manifest声明权限后启动。设备使用SDK构建并用自己的密钥签包。

许可证：Apache-2.0。
