# 文件传输估算

用于计划备份、USB拷贝、局域网或NAS文件传输。

先明确文件大小、容量单位、速率单位和有效效率。GB=10^9字节，GiB=2^30字节；MB/s=10^6字节/秒，Mbps=10^6比特/秒。效率是0到100之间且不含0的百分数。容量和速率必须有限且大于0。

预计秒数=总字节数/（字节速率×效率/100）。页面同时显示秒数及小时/分钟/秒，不把估算声称为测速结果。

验算：8 GiB、100 Mbps、80%得到858.9934592秒；8 GB、100 Mbps、80%得到800秒；8 GB、100 MB/s、80%得到100秒。空输入、负数、0速率、0效率、超过100%效率应显示输入提示，不抛异常、不保存错误历史。

生成工具时先读取plugin.author.contract，只使用已支持组件。分类选择可使用文本框加示例或声明的按钮。保留最近5次正确计算，存储前按UTF-8字节数检查设备配额。更新已有工具先inspect，保留私有数据格式。测试完成后删除自己添加的验收历史，不清除用户原有记录。

只做计算，不自行测速、下载文件、扫描磁盘、启用共享或修改NAS只读设置。技能不增加权限。
