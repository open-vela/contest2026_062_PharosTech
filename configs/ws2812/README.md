# ws2812 — WS2812 灯带配置

在 `dev` 开发调试配置基础上启用 WS2812 灯带：`CONFIG_WS2812_CHARDEV=y`
打开平台驱动层的 WS2812 字符驱动，`CONFIG_KICKPI_K7_WS2812=y` 让板级代码
把它注册为 `/dev/ws2812`；数据线用 SPI3 的 M0 复用（MOSI = GPIO3_A1，
排针 24，VCCIO4 3.3V），SPI3 其余引脚保持默认复用。

驱动不缓存像素、每帧一次 `write()`、`lseek()` 返回 `-ESPIPE`。数据线在
两帧之间由板级的 select 回调切回 GPIO 输出低电平——WS2812 靠 ≥50µs 的
低电平锁存，数据线空闲时若保持高电平会被灯带当成连续的 1 位，下一帧
复位时整条灯带会锁存成白色。多灯带分时复用同一根数据线要等外部多路
选择器硬件就绪后，把它的控制加进同一个 select 回调。

同时编入测试程序 `ws2812_test`（`CONFIG_EXAMPLES_WS2812_TEST=y`）：在
NSH 里直接执行即可，前 16 颗灯先红、绿、蓝各 1 秒，再红 x4/绿 x4/蓝 x4/
白 x4 显示 3 秒，最后熄灭前 16 颗并返回。
